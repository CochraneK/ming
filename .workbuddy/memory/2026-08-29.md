## 第十五轮：新人物发现扫描（回答用户"还能抽取吗"）

用户追问"还能抽取吗"——即从全书原文能否再发现未被抽取的新人物。

### 方法与环境坑
- 新增 `src/discover_persons.py`（纯本地、零 LLM）：扫描章节正文 `body`，三类强信号提取 2-4 字中文片段 →
  主语提取（标点/句首后紧跟 说/道/率/攻…）、封授结构（封/任/拜 X 为…）、表字结构（X，字Y）；
  过滤：常见汉姓白名单 + 排除已知名/别名 + 排除已知长名子串（防伪影）+ 排除代词/官职称谓字。
- **环境坑（跨会话复用）**：Windows 原生 python 读含中文的 .py 源码会报 `invalid character`，须设 `PYTHONUTF8=1`；
  且 python 不认 Git Bash 的 `/d/` POSIX 路径，须用 `D:/2026/WB项目/明朝` 风格绝对路径（通过 `env BASE=` 传入，避免中文命令行字面量乱码）。
- 正则字符类里误写单引号 `'` 会提前闭合 `r'...'` 字符串，引号字符用 `\u201c\u201d` 转义。

### 结果
- 高频层零真实遗漏：主语/封授/表字三信号在阈值≥2 时仅得 9 个候选，全为虚词/短语（相对而/也就是/平分土地/五人…）；表字结构阈值降到 1 也仅 1 个噪声（"江湖州人"是"浙江湖州人"截断误抓，真名温体仁已在卡）。
- 关键人物覆盖抽查（`.dump/check_known.py` 临时，已清理）：96 个各时期明史重要人物，88 个已在卡（含别名）；8 个"缺失"中 **7 个原书 0 次提及**（王越/汤若望/宋应星/袁可立/瞿式耜/刘宗周/陈圆圆——书里根本没写，非遗漏）；仅 **郑成功原书 2 次**，且都是"郑芝龙之子"一笔带过，已通过郑芝龙卡 + data.json 内"郑成功/国姓爷"引用覆盖，无需独立建卡。

### 结论
抽取**已充分**。书中实际出现的人物基本都已建卡；所谓"还能抽"的剩余空间仅是：① 书中压根未写的（无需抽）；② 每章仅 1 次提及的极边角人物（自动方法被噪声淹没，需人工逐章精读，收益极低）。不建议为低频边角强行补录污染数据。

- **`同章另有 N 件事件，未作为地点直接关联。` 噪声**：改为 `同章另提及 N 件事件（未直接落点于本地点）。`，地点详情注记 `（同章提及，未直接落点于本地点；可作圣地巡礼上下文）`。
