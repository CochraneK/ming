## 抽取无法在 agent 环境内运行（重要环境结论）

## ✅ 抽取最终方案：用"自带免费hy3"(=助手/agent 自身)直接抽，不连 omni
- 用户明确："不要连接omni，我目前自带了抽取的免费hy3" → 抽提取代由**模型自身**完成，不走任何外部网关。
- 自建两个助手脚本（src/）：
  - `_dump_chapter.py <key>`：按 key 打印章节 part/chapter/正文（避免把 4.5MB chapters.json 读进上下文）。
  - `_append_extract.py <rec.json>`：安全追加/覆盖抽取记录到 data/extract_raw.json（按 key 去重）。
- 流程（每章）：dump 正文 → 模型按 schema 抽五元组 → Write /tmp/rec.json → `_append_extract.py` 追加 → 每 ~15 章跑一次 `merge.py`。
- schema 与 extract_auto.py 的 SYSTEM_PROMPT 一致：{key,chapter,part,time,characters[{name,aliases,faction,role}],locations[{ancient,mentioned_as}],events[{name,type,participants,location,year}],relations[{from,to,rel}]}。
- 验证批次：我先亲自抽 p2-c1 作标准样例（写入 /tmp/p2c1.json 并追加），确认合并正确（extract_raw 34 条、data.json 重生）。
- 之后用 **后台 general-purpose agent**（run_in_background, max_turns=900）续抽其余 122 章，不连网络、不碰其他文件。
